# Capture Chat Summary from Close Response

## Problem Statement

Chat summary feature is **silently broken**:

- `ChatSummaryCard` renders in `chat/room.tsx` when `sessionClosed=true`
- `useChatSummary` hook fetches `GET /student/courses/{course}/chat-spaces/{id}/summary`
- Laravel proxy forwards to Core API `GET /api/chatspaces/{id}/summary`
- **Core API does not have this endpoint** — only `/close`, `/reopen`, `/status`, `/reflection` exist
- Core 404 → Laravel masquerades as 200 with `{summary: null}` → frontend shows empty state
- Summary IS generated by Core API but only returned in `POST /close` response body, not persisted

Result: feature appears to work, summary card renders, but always shows empty.

## Proposed Solution

Capture summary from the `close` response and pass it to `ChatSummaryCard`:

1. `closeSession` endpoint already returns summary in body (Core API generates via `aiEngineService.generateSummary`)
2. Update `chat/room.tsx`: capture response from `handleCloseSession` POST, store in state
3. Update `useChatSummary` hook: accept optional `initialSummary` from props
4. Remove the broken GET fetch path (or keep as fallback for refresh scenarios)

## Scope

- `app/Http/Controllers/StudentCourseController.php::closeSession` — pass through Core's summary field
- `resources/js/pages/student/chat/room.tsx` — capture summary from close response
- `resources/js/features/chat/summary/use-chat-summary.ts` — accept initial summary prop
- Tests for hook with initial summary

## Out of Scope

- Core API persistence (separate change in core-api repo)
- Summary regeneration UI
